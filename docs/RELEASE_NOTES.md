Islet adds more file formats, image previews and a caller panel for code review.

- Syntax highlighting for JSON, YAML, TOML, shell/Bash, XML, SQL, INI, Dockerfiles and Python requirements files, with automatic filename detection.
- Clear primary text selection in Islands Dark and Light, distinct from other matching occurrences.
- Read-only preview tabs for PNG, JPEG, GIF, WebP, AVIF, BMP and ICO images, with dimensions, fit and zoom controls. Local and SSH workspace images use the same scoped file access, with a 10 MB preview limit.
- Ctrl/Cmd-click uses a hand cursor and reveals definition targets near the top of the editor, with five lines of context above them. Scrolling past the final line keeps end-of-file targets readable too.
- Optional **Callers** panel above the editor, enabled in Settings or using the branch button in the breadcrumbs. Python and JavaScript/TypeScript language services provide up to five caller levels, with clickable function/file/line entries, cycle handling and bounded expansion. This is static caller analysis, not a runtime debugger stack.

Install using the Apple silicon DMG, or use **Check for Updates** in Islet 0.1.2 or newer. Available updates download automatically when enabled and install only after an explicit restart, with unsaved-work protection. macOS 13.5 or newer is required.

The preview remains ad-hoc signed and **not notarized**. Update signatures are verified independently and require no paid Apple Developer membership.
