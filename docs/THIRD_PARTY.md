# Third-party material

Islet retains its own application identity. Interface actions use Lucide. File and folder icons use the JetBrains New UI file icon theme from [fogio-org](https://github.com/fogio-org/vscode-jetbrains-file-icon-theme), pinned to revision `26a200cb06e8f339a2ba610036bcc034d863a34a`. The complete dark/light asset set is bundled locally, with the theme's MIT license and the artwork's Apache 2.0 license in `public/licenses/`. Original SVG copyright comments are retained; `public/icons/jetbrains/NOTICE.md` records provenance and mapping changes, and `SHA256SUMS` records asset hashes. The Islands palette follows public upstream theme definitions.

Inter and JetBrains Mono are bundled through Fontsource, under the SIL Open Font License. Their complete notices ship at `public/licenses/Inter-OFL.txt` and `public/licenses/JetBrains-Mono-OFL.txt` and are copied into the frontend distribution. CodeMirror, React and highlight.js notices are included alongside them.

The bundled Node runtime includes `NODE-LICENSE`. Bundled basedpyright, TypeScript, typescript-language-server and their dependencies retain their package license files in `resources/runtime/node_modules`; remote archives retain the same licenses. Exact versions are recorded in `resources/runtime/versions.json` and dependency lockfiles.

Additional dependencies include Tauri, CodeMirror/Lezer, markdown-it, DOMPurify, Lucide, Vite and their transitive packages. Refer to the lockfiles and original package distributions for the complete version/license provenance. No user project dependencies are copied into Islet's distribution.

Spreadsheet editing bundles Jspreadsheet CE 5.0.4 and its jSuites/MIT Formula Basic dependencies, Papa Parse 5.7.0 (MIT), and SheetJS CE 0.20.3 (Apache 2.0). Their notices ship in `public/licenses/`. SheetJS is pinned to the upstream distribution tarball with an integrity hash in `package-lock.json`; no CDN is used by the running application. The Vite adapter removes CE's inline `onselectstart` handler; the Islet wrapper supplies selection prevention without relaxing the native content security policy. Formula evaluation and HTML interpretation are disabled. No Pro packages, license service, remote fonts, or hosted file converters are used.

DOCX editing pins SuperDoc **1.46.2**, licensed AGPLv3, with a local copy of its `BlankDOCX` template. `public/licenses/SuperDoc-AGPL-3.0.txt` retains the complete license. Source provenance: [SuperDoc repository](https://github.com/superdoc/docx-editor), exact npm package and integrity in `package-lock.json`. SuperDoc 2.x is excluded: it depends on the proprietary `@superdoc/docx-engine`; that package is absent from the final dependency tree and distribution. Telemetry is explicitly disabled. No collaboration or hosted conversion service is configured. System fonts are used without downloading substitutes.

SuperDoc's AGPLv3 terms apply to redistribution of the combined editor; a distributor must provide the required corresponding source and notices, or obtain a suitable alternative license. Islet application source is distributed under AGPLv3 for this release, with the application source and public SuperDoc 1.x source supplied together. Keep the 1.x pin when updating dependencies; do not replace it with 2.x as an ordinary patch upgrade.

ZIP exports use yazl **3.3.1 (MIT)** and buffer-crc32. Its license ships at `public/licenses/yazl-MIT.txt`; both packages and their original notices are also included in desktop and Linux helper runtimes. ZIP generation happens on the file's owning helper host. No external archive service is used.

The Excel/Word/CSV file-type glyphs in `public/icons/office/` are original Islet SVG artwork with separate dark/light colors. They use letter/grid/delimiter symbols and do not bundle Microsoft logo artwork. The resolver uses these in both tree rows and tabs.

Release source provenance for SuperDoc 1.46.2: public 1.x revision `66c22186c7c0735360ca4fd94f7499898415e903`, archive SHA-256 `1b60af9a701e70bffe8661e49f8f88d191dd2faada9d9853c8db30964a235feb`. Its source package declares 1.46.2/AGPL-3.0. The release source bundle includes that complete upstream tree, along with Islet's tagged source and build recipes.
